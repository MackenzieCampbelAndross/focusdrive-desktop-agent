# Development Setup Guide

## Prerequisites
- Node.js (v22+)
- npm (v11+)
- Rust & Cargo (1.92+)
- Visual Studio Build Tools (C++ / MSVC)
- WebView2 Runtime (Included on Windows 10/11)

## Running Locally
```bash
# Install dependencies
npm install

# Run frontend build
npm run build:frontend

# Run Rust tests
npm run test:rust

# Run Tauri dev server
npm run tauri dev
```
